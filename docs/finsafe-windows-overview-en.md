# FinShield Windows product introduction

[简体中文](finsafe-windows-overview-zh.md) · [Documentation](README.md) · [Agent Safety Evaluation](https://agent-safety-arena.finogeeks.club/index.html) ([中文](https://agent-safety-arena.finogeeks.club/zh-CN.html))

FinShield helps enterprises use Agents on Windows computers with greater control: protect computers and business information, and collect operational data produced during work so the enterprise can build its own data assets.

- **Security:** keep Agent actions within granted permissions and reduce accidental changes and information disclosure.
- **Data value:** collect operational data that business work already produces, preserving information that would otherwise be lost.

## Security

The protection model has **three areas and two methods**: the areas define what to protect; the methods define how.

**Three areas: interaction security, system security, and information security.**

- **Interaction security:** restrict unnecessary desktop interaction and reduce interference with other applications and daily work.
- **System security:** restrict unauthorized system changes and control resource use to reduce the effect of mistakes and runaway tasks.
- **Information security:** define which information can be read or changed and which services can be reached. For detected sensitive content, record, block, or request approval according to settings.

**Two methods: permission enforcement and behavioral guidance.**

- **Permission enforcement:** refuse unauthorized operations so the Agent follows its assigned permissions.
- **Behavioral guidance:** explain the permission boundary and guide the Agent toward authorized work rather than repeated attempts to bypass restrictions.

Enforcement stops unauthorized operations; guidance helps the Agent adjust its approach. Together they can reduce unnecessary attempts.

## Data value

Agents produce trace data while working: conversations, tool calls, and results. These records contain real business requirements and processing steps, but can be overlooked or lost when a task ends.

FinShield collects and retains supported business records so enterprises can build data assets while completing their work.

- **Collect existing data:** retain conversations and their supported tool calls and results.
- **Preserve context:** associate sources and sessions so records have an identifiable origin and their business context can be reviewed.
- **Build enterprise assets:** use encrypted local retention and queries to accumulate operational data that the enterprise can save, manage, and use.

## Enterprise benefits

**Help Agents work safely and keep business data under enterprise control.** During normal Agent use, preserve the operational records that could otherwise be lost.
