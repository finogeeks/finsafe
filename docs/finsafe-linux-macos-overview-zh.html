01 / 产品总览

让智能体更安全地工作
让业务数据成为企业可掌握的资产

智安盾（FinShield）帮助企业在Linux与Mac电脑上更放心地使用智能体（Agent）：保护电脑和业务资料，同时收集业务过程中产生的运行数据，帮助企业积累数据资产。

安全保障

让智能体按授权做事，降低误操作和资料泄露的风险。

三纵：保护什么

  • 交互安全减少工作干扰
  • 系统安全降低误操作风险
  • 资料安全控制访问与外发

两横：怎么保护

  • 权限约束拦住越权操作
  • 行为引导减少无谓尝试
了解三纵两横防护 →

数据价值

把业务中已经产生、却容易散失的运行数据收集下来，积累企业可掌握的数据资产。

  • 收集已有数据

    记录任务执行、网络访问与处理结果，把日常业务自然产生的数据留下来。

  • 保留业务上下文

    关联任务与运行记录，让数据有来处、过程可回看。

  • 积累企业资产

    保存和管理运行记录，随着业务持续积累企业自己的数据资产。

02 / 安全保障

三纵明确保护对象
两横结合权限约束与行为引导

三纵讲保护什么，两横讲怎么保护。权限约束与行为引导贯穿交互、系统和资料三重防护。

权限约束：拦住越权操作

未经授权的操作，直接拒绝执行，守住设定的权限。

行为引导：减少无谓尝试

向智能体说明限制与可用做法，引导它放弃反复绕过限制的尝试，按授权继续任务。

三纵防护权限约束：守住边界行为引导：调整做法
交互安全限制未经授权的命令和工具操作，减少工作干扰引导智能体围绕已授权的命令与工具完成任务
系统安全限制系统修改和资源占用，降低误操作风险说明被拒绝的原因与可用做法，减少反复尝试
资料安全控制文件访问、连接目标与敏感内容外发引导智能体使用已授权的资料与服务继续任务
三纵两横，共同防护权限约束守住边界，行为引导帮助智能体调整做法，减少无谓尝试。
能力展开交互安全系统安全资料安全

交互安全：减少工作干扰

通过受控命令与工具执行任务，减少对其他工作和业务资料的影响。

系统安全：降低误操作风险

分别使用Linux与macOS的原生安全机制，限制Agent的系统操作、资料访问和任务执行范围。

控制能力LinuxmacOS
执行环境bubblewrap挂载视图与命名空间，隔离受控程序的运行环境以原生Seatbelt策略约束程序，无需为本机任务准备Linux环境
系统操作seccomp过滤所选高危系统调用；user namespace隔离所选身份上下文Seatbelt按策略限制文件、进程和网络操作
文件访问挂载规则与Landlock按所选运行路径组合，控制读写范围Seatbelt生成路径允许与拒绝规则，控制资料读写
资源与时限cgroup v2设置CPU、内存、进程数配额；短任务可配置执行时限短任务可按策略配置执行时限
按平台配置防护Linux适合需要细粒度资源配额的任务节点；Mac侧重原生文件与网络访问控制，两平台可统一管理授权策略与运行记录。

Linux：bubblewrap 0.5.0或更高版本，按需配置seccomp、cgroup v2委派、Landlock及配套组件。macOS：通过系统sandbox-exec应用Seatbelt，本机运行无需Linux helper。

资料安全：控制访问与外发

通过文件授权控制资料使用，通过受控出口管理连接目标与敏感内容。

授权范围权限允许操作
任务工作目录可读写创建、读取、修改及删除授权范围内的文件
参考资料目录只读查阅内容；禁止修改和删除
私密资料目录禁止读取通过显式禁止读取规则或隔离视图限制访问
外发控制处理方式覆盖边界
network: none按启动路径应用无网络策略本地服务与模型连接按所选策略配置
network: allowlist在受控代理检查域名、端口及配置的IP字面量规则代理与沙箱边界共同限制未经授权的外连
network: host允许宿主网络；启用Privacy Guard时可编译为强制代理路径白名单和内容检查需按相应策略启用
TLS与隐私检查仅对经代理、可解密且格式受支持的内容执行检测及改写／阻止证书固定、不透明隧道和未支持格式没有完整内容覆盖

可选的NER文本识别与OCR图片识别需要部署检测器和签名模型；内容检查范围取决于请求路径、TLS可检查性及支持的载荷格式。

03 / 数据价值

业务照常开展
数据资产同步积累

智能体处理业务时，会产生任务执行、网络访问和策略处理结果等运行过程数据（Trace Data）。这些数据记录着真实的业务需求和处理过程，却容易在任务结束后被忽略或散失。

智安盾把这些业务“副产物”收集并保存下来，让企业在完成工作的同时，也能积累自己的数据资产。

收集已有数据

记录任务执行、网络访问与策略处理结果，把日常业务自然产生的数据留下来。

保留业务上下文

关联任务、执行标识与处理记录，让数据有来处、过程可回看，保留业务背景与联系。

积累企业资产

持续保存运行记录，让数据随着业务开展积累，成为企业可以保存、管理和利用的数据资源。

让记录有来处、过程可回看

任务执行记录

保留执行标识、退出状态和策略证据，帮助回看任务结果。

网络与策略记录

记录连接目标、放行或拒绝及原因，关联对应任务与执行环境。

数据已经产生，价值现在留存把原本容易忽略、散失的过程数据收集起来，让每一次业务开展都能留下可掌握的数据资产。

05 / 应用与接入

沿用现有工具与业务场景
按授权开展任务

适用于Linux开发机、企业工作节点和Mac工作电脑，以及接入执行平台的工具任务。

应用场景授权方式业务价值
研发与代码助手项目目录可写；依赖和参考资料只读；模型及仓库按需联网在授权项目中完成编译、测试与代码操作
运维与自动化开放指定日志、工作目录与业务接口；按平台配置执行约束将自动化操作限制在指定目录、接口与资源范围内
企业知识与文档处理资料按目录授权；外发经过批准的目标和检查路径按授权使用资料，按策略检查可见的敏感内容
平台工具执行通过适配器或执行服务调度受控命令统一执行入口，关联任务、结果与审计记录
安全使用，统一管控保护机器与业务资料，约束Agent的资源使用与数据外发；通过统一策略与运行记录管理企业中的Agent。

原生接入，沿用现有工作方式

轻量运行

复用Linux与macOS原生安全机制，让Agent在授权环境中使用工具和资料，减少为每个任务维护独立虚拟机的需要。

权限由使用方掌握

个人和企业定义文件、网络与资源范围；智安盾在受控执行路径上落实策略。

从单机走向企业治理

通过签名策略、终端服务和审计记录，统一管理企业中的Agent执行权限。
