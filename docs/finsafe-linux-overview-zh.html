01

轻量运行

复用 Linux 与 macOS 原生安全机制，让 Agent 在授权环境中使用工具和资料，减少为每个任务维护独立虚拟机的需要。

02

权限由使用方掌握

个人和企业定义文件、网络与资源范围；智安盾在受控执行路径上落实策略。

03

从单机走向企业治理

通过签名策略、终端服务和审计记录，统一管理企业中的 Agent 执行权限。

保护对象智安盾帮你管什么直接价值
机器安全按平台落实系统操作约束与文件写入权限减少误操作对主机和其他任务的影响
资源使用Linux 支持资源配额；两平台支持短任务执行时限减少失控任务占满资源的风险
数据安全划分可读写、只读和禁止读取范围让资料访问符合任务授权
数据外发限制连接目标，对可检查请求应用隐私防护减少越权外连与敏感信息外发风险
控制执行权限模型决定如何完成任务，智安盾约束受保护进程实际能访问的资源。

放进可管理的业务范围

应用场景授权方式业务价值

运维与自动化开放指定日志、工作目录与业务接口；按平台配置执行约束将自动化操作限制在指定目录、接口与资源范围内

平台工具执行通过适配器或执行服务调度受控命令统一执行入口，关联任务、结果与审计记录
安全使用，统一管控保护机器与业务资料，约束 Agent 的资源使用与数据外发；通过统一策略与运行记录管理企业中的 Agent。

Agent 运行数据 · Trace Data

沉淀企业数据资产，支持研发持续改进

按配置采集已接入 Agent 的交互、模型调用、工具执行与处理结果等 Trace Data，让真实业务中的任务与执行经验成为企业可积累、可复用的数据资产。

积累数据资产

支持研发改进

过程可追溯

关联交互内容、执行结果与策略处理记录，帮助回看任务过程、定位异常和开展安全审计。

04 机器安全

限制高危操作
控制任务资源占用

分别使用 Linux 与 macOS 的原生安全机制，限制 Agent 的系统操作、资料访问和任务执行范围。

控制能力LinuxmacOS
执行环境bubblewrap 挂载视图与命名空间，隔离受控程序的运行环境以原生 Seatbelt 策略约束程序，无需为本机任务准备 Linux 环境
系统操作seccomp 过滤所选高危系统调用；user namespace 隔离所选身份上下文Seatbelt 按策略限制文件、进程和网络操作
文件访问挂载规则与 Landlock 按所选运行路径组合，控制读写范围Seatbelt 生成路径允许与拒绝规则，控制资料读写
资源与时限cgroup v2 设置 CPU、内存、进程数配额；短任务可配置执行时限短任务可按策略配置执行时限
按平台配置防护Linux 适合需要细粒度资源配额的任务节点；Mac 侧重原生文件与网络访问控制，两平台可统一管理授权策略与运行记录。

Linux：bubblewrap 0.5.0 或更高版本，按需配置 seccomp、cgroup v2 委派、Landlock 及配套组件。macOS：通过系统 sandbox-exec 应用 Seatbelt，本机运行无需 Linux helper。

05 数据安全

资料按授权使用
外发按策略控制

通过文件授权控制资料使用，通过受控出口管理连接目标与敏感内容。

授权范围权限允许操作
任务工作目录可读写创建、读取、修改及删除授权范围内的文件
参考资料目录只读查阅内容；禁止修改和删除
私密资料目录禁止读取通过显式禁止读取规则或隔离视图限制访问
外发控制处理方式覆盖边界
network: none按启动路径应用无网络策略本地服务与模型连接按所选策略配置
network: allowlist在受控代理检查域名、端口及配置的 IP 字面量规则代理与沙箱边界共同限制未经授权的外连
network: host允许宿主网络；启用 Privacy Guard 时可编译为强制代理路径白名单和内容检查需按相应策略启用
TLS 与隐私检查仅对经代理、可解密且格式受支持的内容执行检测及改写／阻止证书固定、不透明隧道和未支持格式没有完整内容覆盖

可选的 NER 文本识别与 OCR 图片识别需要部署检测器和签名模型；内容检查范围取决于请求路径、TLS 可检查性及支持的载荷格式。

企业托管 · C4 L2

蓝色：智安盾系统或运行程序灰色：外部系统虚线框：软件系统边界箭头：调用或数据流向

终端执行入口从本机策略服务取得有效策略，策略服务负责与中心同步策略、心跳及审计记录。

查看组件与部署关注点
组件职责部署关注点
finsafe-authority-http管理与分发策略、注册和接收审计部署有效商业许可、服务认证和签名信任
finsafe-agent注册、签名校验、缓存、本机策略服务Linux 使用 systemd，macOS 使用 LaunchDaemon 维护终端策略服务

Linux 可通过 Ansible、主机镜像或现有配置管理工具部署；Mac 可通过 Jamf、MDM 或现有终端管理工具部署，统一结合设备注册与托管策略管理。
