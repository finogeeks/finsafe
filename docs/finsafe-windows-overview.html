01 / 产品总览

让智能体更安全地工作
让业务数据成为企业可掌握的资产

智安盾（FinShield）帮助企业在Windows电脑上更放心地使用智能体（Agent）：保护电脑和业务资料，同时收集业务过程中产生的运行数据，帮助企业积累数据资产。

安全保障

让智能体按授权做事，降低误操作和资料泄露的风险。

三纵：保护什么

  • 交互安全减少工作干扰
  • 系统安全降低误操作风险
  • 资料安全控制访问与外发

两横：怎么保护

  • 权限约束拦住越权操作
  • 行为引导减少无谓尝试

02 / 安全保障

三纵明确保护对象
两横结合权限约束与行为引导

三纵讲保护什么，两横讲怎么保护。权限约束与行为引导贯穿交互、系统和资料三重防护。

权限约束：拦住越权操作

未经授权的操作，直接拒绝执行，守住设定的权限。

行为引导：减少无谓尝试

向智能体说明限制与可用做法，引导它放弃反复绕过限制的尝试，按授权继续任务。

三纵防护权限约束：守住边界行为引导：调整做法
交互安全限制未经授权的桌面操作，减少对其他应用的干扰引导智能体围绕已授权的应用与任务工作
系统安全限制系统修改和资源占用，降低误操作风险说明被拒绝的原因与可用做法，减少反复尝试
资料安全控制文件访问、连接目标与敏感内容外发引导智能体使用已授权的资料与服务继续任务
三纵两横，共同防护权限约束守住边界，行为引导帮助智能体调整做法，减少无谓尝试。
能力展开交互安全系统安全资料安全行为引导

交互安全：减少工作干扰

限制不必要的桌面交互，减少智能体对其他应用和日常工作的影响。

系统安全：降低误操作风险

限制未经授权的系统修改，控制资源占用，减少误操作和任务失控对电脑的影响。

高危操作防护

注册表与启动配置破坏系统配置，严重时Windows无法启动注册表、受保护文件及系统管理接口的访问检查
进程与系统服务关键程序崩溃、服务中断，影响系统正常运行进程句柄、服务管理器及服务对象权限检查
账户、任务与启动项留下高权限账户或自动执行入口，持续影响系统安全账户管理、计划任务及启动位置的访问检查
网络、安全设置与日志网络连接异常、安全防护失效，或丢失排查记录网络与安全配置权限及日志管理接口的访问检查
原始磁盘写入损坏分区或文件系统，导致数据无法访问原始设备写句柄权限检查

资源占用控制

内存与进程限制

运行与退出管理

工具执行支持超时终止与进程树清理，减少长时间运行和子进程残留

明确哪些资料可以读取、修改，以及允许访问哪些服务；对检测到的敏感内容，按设置提醒、阻止或询问。

03 / 数据价值

业务照常开展
数据资产同步积累

智能体处理业务时，会产生对话、工具调用和处理结果等运行过程数据（Trace Data）。这些数据记录着真实的业务需求和处理过程，却容易在任务结束后被忽略或散失。

智安盾把这些业务“副产物”收集并保存下来，让企业在完成工作的同时，也能积累自己的数据资产。

收集已有数据

记录对话及其中的工具调用、处理结果，把日常业务自然产生的数据留下来。

保留业务上下文

关联记录的来源与会话，让数据有来处、过程可回看，保留真实业务的背景与联系。

积累企业资产

通过本地加密留存和查询，让运行数据随着业务开展持续积累，成为企业可以保存、管理和利用的数据资源。

让数据留得下来、查得到

AES-GCM＋用户DPAPI
本地加密存储

按配置留存请求、响应与处理结果，加密保存记录，使用用户DPAPI保护密钥

查看与追溯

查看请求内容、响应和策略处理结果，区分完整记录与中断记录

数据已经产生，价值现在留存把原本容易忽略、散失的过程数据收集起来，让每一次业务开展都能留下可掌握的数据资产。
