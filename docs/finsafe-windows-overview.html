02 / 机器安全

高危操作，可能让整台电脑无法正常使用

编辑文件、安装依赖、排查故障时，Agent也可能调用系统管理接口这是具备执行能力的Agent普遍需要面对的风险

高危操作为什么危险
修改关键注册表配置误改系统、启动或驱动配置，可能造成程序异常，甚至让Windows无法启动
修改系统权限或所有者误改后，文件或程序可能无法访问；放宽权限，则可能让未授权程序取得访问权
变更系统服务或后台任务停用关键服务可能导致系统功能失效；新增后台任务可能让程序持续运行
修改防火墙或直接写磁盘错误的规则可能暴露网络入口；底层磁盘写入可能破坏分区和数据

智安盾限制受控Agent的未授权系统操作，将日常工作与系统管理权限分开

资源失控，也会影响工作

内存占满、进程过多，可能让电脑卡顿、程序崩溃

内存上限

限制任务使用的内存

进程数上限

限制任务启动的进程数量

执行时限

终止超过适用时限的任务
