# WorkBuddy 试用：安装与现场演示

> **状态：可对外试用，非正式支持。** 给销售和新同事 10 分钟上手。讲价值和边界时用 [防护概览](./workbuddy-protection-overview-zh.md)。不要说成 GA 或公开自助安装。

先装 **WorkBuddy**，再装 **FinSAFE**。本机已有 WorkBuddy 可跳过第一步。

## 1. 安装并打开防护

1. 运行 FinSAFE 安装包，按提示选安装目录，装完可勾选立即打开。
2. 若没自动打开：点桌面或开始菜单里的 **FinSAFE**。
3. 向导里选模式，再点 **启用防护**：
   - **体验**：培训机、现场演示用（不弹管理员提示）。
   - **常规（生产推荐）**：给客户长期用；可能弹出系统提示，选是即可。
4. 等到 **防护成功**。第一次可能要等一会儿。
5. **完全退出并重新打开 WorkBuddy**，再开始演示。

找不到 WorkBuddy：先打开一次 WorkBuddy，回到向导点重试。

## 2. 现场演示（两条）

**工作区不要选桌面、文档，也不要打开已有项目。** 在 WorkBuddy 里新建任务，用它默认的工作区（会落在用户目录下的 `WorkBuddy` 文件夹）。

| 让助手做什么 | 期望 |
|--------------|------|
| 在**当前任务**里新建一个文件，例如 `hello.txt` | 成功，文件出现在任务目录 |
| 再在**桌面**（或「文档」）生成一个文件 | 失败，桌面上不应出现该文件 |

第一条证明「正常工作还在」；第二条证明「越界写入被拦住」。不要演示读机密或锁网。

装完要卸载：开始菜单 **卸载 FinSAFE**。防护讲解仍看 [防护概览](./workbuddy-protection-overview-zh.md)。
