# FinShield Linux/macOS product introduction

[简体中文](finsafe-linux-macos-overview-zh.md) · [Documentation](README.md)

FinShield helps enterprises use Agents on Linux and Mac computers with greater control: protect computers and business information, and collect operational data produced during work so the enterprise can build its own data assets.

- **Security:** keep Agent actions within granted permissions and reduce accidental changes and information disclosure.
- **Data value:** collect operational data that business work already produces, preserving information that would otherwise be lost.

## Security

The protection model has **three areas and two methods**: the areas define what to protect; the methods define how.

**Three areas: interaction security, system security, and information security.**

- **Interaction security:** use controlled commands and tools to reduce interference with other work and business information.
- **System security:** restrict unauthorized system changes and apply platform-specific resource controls and task time limits to reduce the effect of mistakes and runaway tasks.
- **Information security:** define which information can be read or changed and which services can be reached. Apply policy to inspectable sensitive content through controlled egress.

**Two methods: permission enforcement and behavioral guidance.**

- **Permission enforcement:** refuse unauthorized operations so the Agent follows its assigned permissions.
- **Behavioral guidance:** explain the permission boundary and guide the Agent toward authorized work rather than repeated attempts to bypass restrictions.

Enforcement stops unauthorized operations; guidance helps the Agent adjust its approach. Together they can reduce unnecessary attempts.

## Data value

Agents produce trace data while working: task execution, network access, and policy decisions. These records contain real business requirements and processing steps, but can be overlooked or lost when a task ends.

FinShield collects and retains supported business records so enterprises can build data assets while completing their work.

- **Collect existing data:** retain execution, network, and policy records produced during normal work.
- **Preserve context:** associate tasks, execution identifiers, and processing records so their origin and business context can be reviewed.
- **Build enterprise assets:** retain operational records over time as enterprise-controlled resources that can be saved, managed, and used.

## Enterprise benefits

**Help Agents work safely and keep business data under enterprise control.** During normal Agent use, preserve the operational records that could otherwise be lost.
