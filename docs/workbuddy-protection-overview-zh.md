# WorkBuddy 防护概览（Windows）

> **状态：可对外试用，陪跑对照，非正式支持。** 给销售投屏、和客户过边界用。不要说成 GA 或公开自助安装。安装与现场演示见 [销售培训安装](./workbuddy-trial-sales-install-zh.md)。

FinSAFE 不替代 WorkBuddy，也不屏蔽官方 LLM 通道。它保护的是本机执行路径：模型仍可提出工具请求，越界写入按策略被拦住。

## 装上之后，客户能看见什么

**工作区不要选桌面、文档，也不要打开已有项目。** 在 WorkBuddy 里新建任务，用它默认的工作区（会落在用户目录下的 `WorkBuddy` 文件夹）。状态目录是 `%USERPROFILE%\.workbuddy`。这两处可以写；打开的工程目录、桌面、「文档」不行。

### 1. 误改「文档」里的文件

| 装之前 | 装之后 |
|--------|--------|
| 让助手把内容写到「文档」，文件会出现 | 当前任务目录里照常能写；写到「文档」会失败 |

### 2. 点了 Full Access

| 装之前 | 装之后 |
|--------|--------|
| 原厂沙箱基本不再约束 | Full Access 跳过的是 WorkBuddy 自己的沙箱，跳不过 FinSAFE。再写「文档」仍应失败 |

### 3. 模型手滑，或网页里藏了指令

| 装之前 | 装之后 |
|--------|--------|
| 模型真去改桌面、清文件时，没有外层拦住 | 越界写入仍按第 1 条被挡；正常改当前任务不受影响 |

### 4. 关掉 WorkBuddy 之后

| 装之前 | 装之后 |
|--------|--------|
| 终端、Python、git 有时还会留着 | 从托盘退出，这些后续进程应被一起收掉 |

试用默认仍允许读取文件，也不锁外网。读机密、锁网是下一步，不要拿来当本周演示。

## 一分钟看懂

WorkBuddy 不只是一个聊天窗口。远端大模型可以建议调用工具，而真正读取文件、修改代码、运行 PowerShell/Python/git、启动 MCP 和访问网络的，是员工电脑上的 WorkBuddy。

AI 安全的关键不只是“模型说了什么”，而是：模型能调用哪些工具、这些工具能访问哪些本机资源、越权时系统能否阻止。

## 三种姿态（同一张图，只改变保护状态）

连线颜色：

- **红色：** 未被 FinSAFE 控制
- **黄色：** 正常入口有门卫，能挡住常见越权，但不是不可绕过
- **绿色：** 门本身已经上锁（Windows 强制）
- **蓝色：** 官方 LLM 正常通道

**黄色**不是“没有防护”。**绿色**保证更强，不依赖 WorkBuddy 主动配合。

投屏请打开同目录的 [HTML](./workbuddy-protection-overview-zh.html)，可在「裸跑 / 试用方案 / 厂商配合」之间切换。

### 方案 A：WorkBuddy 裸跑

原厂沙箱主要管被送入沙箱的命令。进程内改文件、以及用户批准的 Full Access，仍可能按登录用户权限执行。

### 方案 B：FinSAFE 试用方案（不要求厂商改代码）

本地工具进程（shell / Python / git / 本地 MCP）进入 Windows 强制限制。进程内写入由 FinSAFE 在正常入口把关。即使用户点 Full Access，也不能跳过这层。

网络这次试用仍走主机，可记录、不锁定。

### 方案 C：WorkBuddy 配合方案

若厂商提供稳定启动接口，Agent Core 可以从创建时就进入受限环境，文件、网络和 MCP 再统一变成绿色。这是升级路径，不是本周试用承诺。

| 客户关心的问题 | 裸跑 | 试用方案 | 厂商配合 |
|----------------|------|----------|----------|
| 修改或删除工作区外的文件 | 多数使用登录用户权限 | 进程内部分防护；本地工具强制防护 | 统一强制边界 |
| 运行命令或本地工具 | 原厂沙箱；Full Access 可绕过 | Full Access 仍经过 FinSAFE | 核心和后代都在受限环境 |
| 访问 Web | 主机网络 | 仍走主机，可审计 | 统一受控出口 |
| 关掉后进程是否还在 | 依赖原厂 | 一并收掉 | 从核心创建时统一管理 |

## 对客户怎么说

适合说：**「FinSAFE 为 WorkBuddy 的模型驱动工具执行增加可验证的分层防护。」**

不要说：**「已经把整个 WorkBuddy 完全沙箱化。」** 也不要说「纳管」——那是另一套舰队托管能力。

## 边界

- 保护的是 LLM 能触发的本机工具路径，不是界面、更新器和全部厂商代码
- 允许读、限制写，是当前试用选择
- 每个 WorkBuddy 版本都要再验证，不能口头宣布任意版本已支持
