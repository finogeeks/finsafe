# 智安盾Windows产品提要

智安盾（FinShield）帮助企业在Windows电脑上更放心地使用智能体（Agent）：保护电脑和业务资料，同时收集业务过程中产生的运行数据，帮助企业积累数据资产。

- **安全保障**：让智能体按授权做事，降低误操作和资料泄露的风险。
- **数据价值**：把业务中已经产生、却容易散失的运行数据收集下来，积累企业可掌握的数据资产。

## 安全保障

安全防护分为“三纵两横”：**三纵讲保护什么，两横讲怎么保护。**

**三纵：交互安全、系统安全、资料安全。**

- **交互安全，减少工作干扰**：限制不必要的桌面交互，减少智能体对其他应用和日常工作的影响。
- **系统安全，降低误操作风险**：限制未经授权的系统修改，控制资源占用，减少误操作和任务失控对电脑的影响。
- **资料安全，控制访问与外发**：明确哪些资料可以读取、修改，以及允许访问哪些服务；对检测到的敏感内容，按设置提醒、阻止或询问。

**两横：权限约束、行为引导。**

- **权限约束，拦住越权操作**：直接拒绝未经授权的操作，让智能体遵守设定的权限。
- **行为引导，减少无谓尝试**：向智能体说明权限要求，引导它放弃反复绕过限制的尝试，按授权继续任务。

权限约束拦住越权操作，行为引导帮助智能体调整做法，两者配合，减少无谓尝试。

## 数据价值

智能体处理业务时，会产生对话、工具调用和处理结果等运行过程数据（Trace Data）。这些数据记录着真实的业务需求和处理过程，却容易在任务结束后被忽略或散失。

智安盾把这些业务“副产物”收集并保存下来，让企业在完成工作的同时，也能积累自己的数据资产。

- **收集已有数据**：记录对话及其中的工具调用、处理结果，把日常业务自然产生的数据留下来。
- **保留业务上下文**：关联记录的来源与会话，让数据有来处、过程可回看，保留真实业务的背景与联系。
- **积累企业资产**：通过本地加密留存和查询，让运行数据随着业务开展持续积累，成为企业可以保存、管理和利用的数据资源。

## 企业收益

**让智能体更安全地工作，让业务数据成为企业可掌握的资产。** 企业在日常使用智能体的同时，收集和保存运行记录，把原本容易散失的过程数据留在自己手中。
