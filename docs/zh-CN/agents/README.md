# Agent 接入

[English](../../en/agents/README.md) · [Documentation](../README.md)

按[兼容矩阵](compatibility.md)选择平台和 Agent 形态。[Codex CLI](codex.md)和[Claude Code CLI](claude.md)已支持文档中的 Windows 命令行接入路径。DSH 可使用[已发布的 Windows 插件](https://github.com/finogeeks/finsafe/blob/main/integrations/dsh/windows/README-zh.md)。WorkBuddy 桌面入口见[接入指南](workbuddy.md)。插件交付状态与 CLI 支持情况分别说明。

Windows 还支持 [OpenCode Desktop 插件或桌面入口](https://github.com/finogeeks/finsafe/blob/main/integrations/opencode/windows/README-zh.md)、[Hermes Desktop 桌面入口](../getting-started/install.md#hermes-desktop)和 [Kilo CLI 本地交互 TUI 测试插件](../getting-started/install.md#kilo-cli)。各入口的安装方式、版本和保护状态确认见对应章节。
