# 参考资料与支持

[English](../../en/reference/README.md) · [Documentation](../README.md)

CLI 参数以所安装版本的 `finsafe help` 为准，文档版本范围见[兼容矩阵](../agents/compatibility.md)，技术背景见[白皮书](whitepaper.md)。排障步骤见[Codex](../agents/codex.md#常见问题)、[Claude](../agents/claude.md#常见问题)和[安装指南](../getting-started/install.md#获取帮助)。[问题反馈](https://github.com/finogeeks/finsafe/issues/new/choose)请附脱敏证据。产品问题走公开反馈入口，敏感报告使用支持渠道。

[公开版本历史快照](changelog.md)保留已公开的旧版变更；最新安装包以发布页为准。

## 高级配置与命令行

[高级配置与 CLI 参考](cli-configuration.md)解释正式、实验性与内部参数的区别，以及适用入口、默认值和配置生效规则。界面没有设置项时，先确认当前版本是否提供受支持的 CLI 操作；不要只凭字段名或参数能被解析就认定功能有效。

## AI 可读文档

[文档索引](https://finshield.finogeeks.club/zh-CN/llms.txt)按主题链接到本站各页的 Markdown 版本。内容与网页同源，不另设能力声明。入口索引也可从 [llms.txt](https://finshield.finogeeks.club/llms.txt)读取。它便于按需读取，不保证搜索收录或某个模型的回答结果。

[使用 AI 完成集成](../development/ai-integration.md)提供任务提示模板与结果核对步骤。工具可读取[机器目录](https://finshield.finogeeks.club/docs.json)选择页面，再读取[开发主题索引](https://finshield.finogeeks.club/zh-CN/development/llms.txt)。批量处理可使用[当前文档全文包](https://finshield.finogeeks.club/zh-CN/llms-full.txt)；历史快照单列链接，不并入当前操作正文。
