02 / 安全管控

四重明确保护对象，两横配合落实管控

面向主流 Agent，四重覆盖隐私、交互、系统与数据安全；两横结合权限管控与主动诱导、善意劝导。

四重安全被动防御：权限管控主动防御：主动诱导、善意劝导
隐私安全约束摄像头、麦克风与屏幕访问引导使用任务所需信息，尊重隐私边界
交互安全约束或隔离窗口、输入与剪贴板操作引导使用获准工具，减少工作干扰
系统安全限制系统修改、进程操作与资源使用说明限制，劝导放弃绕过权限的反复尝试
数据安全控制资料读写、联网与敏感内容外发引导使用获准资料、服务及处理路径
管住操作，引导行为权限管控守住边界，主动防御帮助 Agent 在边界内继续工作。

具体覆盖按平台、接入方式与策略确认；劝导不改变权限，也不取消拦截。
