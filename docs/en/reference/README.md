# Reference and support

[简体中文](../../zh-CN/reference/README.md) · [Documentation](../README.md)

Use the installed version's `finsafe help` for CLI options, the [compatibility matrix](../agents/compatibility.md) for documented version scope, and the [whitepaper](whitepaper.md) for technical context. Troubleshooting is included in the [Codex](../agents/codex.md#troubleshooting), [Claude](../agents/claude.md#troubleshooting) and [installation](../getting-started/install.md#get-help) guides. [Report a problem](https://github.com/finogeeks/finsafe/issues/new/choose) with redacted evidence. Product defects belong in the public intake; sensitive reports use the support channel.

The [public release history snapshot](changelog.md) preserves historical entries. Use the releases page for current downloads.

## Advanced configuration and CLI

[Advanced configuration and CLI reference](cli-configuration.md) explains supported, experimental and internal parameters, their applicable routes, defaults and activation rules. If the interface has no setting, first confirm that your release offers a supported CLI operation. A field name or accepted argument alone does not prove that a feature is active.
