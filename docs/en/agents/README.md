# Agent integration

[中文](../../zh-CN/agents/README.md) · [Documentation](../README.md)

Use the [compatibility matrix](compatibility.md) to select a platform and Agent form. [Codex CLI](codex.md) and [Claude Code CLI](claude.md) already support command-line integration on the documented Windows route. DSH uses its [released Windows plugin](https://github.com/finogeeks/finsafe/blob/main/integrations/dsh/windows/README.md). WorkBuddy desktop setup is in its [integration guide](workbuddy.md). Plugin availability and CLI support are recorded separately.

Windows also supports the [OpenCode Desktop plugin or desktop launcher](https://github.com/finogeeks/finsafe/blob/main/integrations/opencode/windows/README.md), the [Hermes Desktop launcher](../getting-started/install.md#hermes-desktop), and the [Kilo CLI local interactive TUI test plugin](../getting-started/install.md#kilo-cli). See each section for installation, versions, and protection status checks.
