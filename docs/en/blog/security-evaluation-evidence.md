This page contains the planned sections. Mechanism analysis, reproduction scripts and test results will be added later.

## Define the proposition

- Actor, target object, operation, policy and expected effect.
- Scope across local tools, remote services and versions.

## Collect evidence at each layer

- Model decisions, tool execution, process identity and system outcomes.
- Independent observations of files, windows and receiver payloads.

## Functional and policy controls

- Calibration with synthetic data and disposable resources.
- Fixed inputs and environments with recorded permission changes.

## Approval stages and outcome classification

- Initial interruption, approval and subsequent execution.
- Model refusal, environment errors, system denial, non-applicable and indeterminate results.

## Scoring and evidence packages

- Denominators, repetition counts, retry conditions and versions.
- Public cases, original observations and scoped conclusions to be added.
