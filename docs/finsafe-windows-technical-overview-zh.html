03 / 机器安全

限制Agent“破坏”系统的能力

修改系统配置或关键权限，可能导致程序失效、文件无法访问，甚至让Windows无法启动

高危操作防护

AppContainer＋Windows访问检查
危险动作可能后果防护机制
权限与所有者变更破坏访问权限，导致文件或程序无法使用对象权限检查（WRITE_DAC · WRITE_OWNER）
注册表与启动配置破坏系统配置，严重时Windows无法启动注册表、受保护文件及系统管理接口的访问检查
进程与系统服务关键程序崩溃、服务中断，影响系统正常运行进程句柄、服务管理器及服务对象权限检查
账户、任务与启动项留下高权限账户或自动执行入口，持续影响系统安全账户管理、计划任务及启动位置的访问检查
网络、安全设置与日志网络连接异常、安全防护失效，或丢失排查记录网络与安全配置权限及日志管理接口的访问检查
原始磁盘写入损坏分区或文件系统，导致数据无法访问原始设备写句柄权限检查

资源占用控制

Job Object＋执行生命周期管理
内存与进程限制

限制Agent及工具子进程占用的内存和创建的进程数量，减少对其他程序的影响

运行与退出管理

工具执行支持超时终止与进程树清理，减少长时间运行和子进程残留

04 / 数据安全

控制Agent的数据访问与外发

越权读取、误删文件或发送敏感内容，可能造成资料损坏、隐私泄露和业务数据外流

文件访问控制

Capability SID＋文件ACL
目录示例访问权限允许操作
D:\工作项目可读写创建、读取、修改、删除、重命名与移动
D:\参考资料只读列举、读取与检索
D:\私人资料禁止访问禁止列举、读取与写入

数据外发控制

WFP＋受控代理＋PII检查
控制项目处理方式
连接目标限制可访问的域名与IP，通过受控代理检查请求
HTTPS内容检查启用TLS解密检查，识别支持的当前输入内容中的敏感信息
PII告警命中规则后记录告警，继续发送原请求
PII阻断命中规则后拒绝发送，阻止该请求到达目标服务
PII单次审批命中后等待确认，同意仅放行本次请求，取消或超时不发送

数据留存

AES-GCM＋用户DPAPI
本地加密存储

按配置留存请求、响应与处理结果，加密保存记录，使用用户DPAPI保护密钥

查看与追溯

查看请求内容、响应和策略处理结果，区分完整记录与中断记录
